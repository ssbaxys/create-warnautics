# CBC: More Content

**CBC: More Content** — аддон для [Create Big Cannons](https://modrinth.com/mod/create-big-cannons) на NeoForge: размещаемые **авиабомбы**, **кассетный сброс**, **морская бомба** и **мины**. Баллистика CBC, свои FX/звуки, мягкая совместимость с кораблями Sable и колёсами Offroad.

## Возможности

### Авиабомбы
- **Малая / средняя / большая** — ставятся как блоки
- Нос смотрит в сторону клика; **фронт редстоуна** запускает вдоль оси
- Гаечный ключ Create: поворот / Shift+ПКМ — подобрать
- Кратер через логику CBC-снарядов, авиационные звуки, сильная тряска камеры
- Большинство блоков испаряется (меньше дропа); рядом стоящие бомбы могут сдетонировать по цепочке

### Кассета (малая бомба)
- До **4** малых бомб в одном блоке (склейка ПКМ в выживании или готовые предметы в креативе)
- Под питанием выбрасывает **по одной** (~1.3 с); снятие сигнала останавливает сброс
- Визуальные штанги кассеты на блоке и предмете

### Морская бомба
- Мощность между малой и средней
- В воздухе / по земле — обычный взрыв
- В воде: пропеллер, погружение, детонация с мощным всплеском

### Мины
- **Малая** — противопехотная (шаг / касание живых существ)
- **Большая** — противотранспортная (контакт корпуса Sable; луч колёс Offroad, если мод установлен)
- Короткая задержка взведения после установки

## Требования

| | |
|---|---|
| Minecraft | **1.21.1** |
| Загрузчик | **NeoForge 21.1.x** |
| Обязательно | [Create](https://modrinth.com/mod/create) **6.0.10+**, [Create Big Cannons](https://modrinth.com/mod/create-big-cannons) **5.11.x**, Ritchie's Projectile Library (зависимость CBC) |

### Опционально
| Мод | Эффект |
|---|---|
| [Sable](https://modrinth.com/mod/sable) | Сброс с корабля с инерцией / позой плота; большая мина от корпуса |
| Create Offroad | Большая мина от касания колёс |
| Create Simulated | Секция бомб/мин во вкладке Simulated |
| sable_player_ragdoll / ragdoll_reactions | Мягкий ragdoll от взрыва (без двойного запуска, если есть Reactions) |

## Крафт
Рецепты на материалах CBC / Create (packed guncotton, железные пластины, пороховые заряды и т.д.). **Большая бомба** — механический крафт Create.

## Примечания
- Сборка под NeoForge 1.21.1 + Create 6 / CBC 5.11
- Sable / Offroad / Simulated **не обязательны** для загрузки мода
